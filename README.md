# REVENANTAL

**SOLID STATE · MODEL RV-404**

_Television Receiver · Operating Instructions_

Welcome to your new set. Inside is a directory of the projects, tools and game servers around revenantal.com, with a few things to play along the way.

Turn the dial and see what’s on.

## 1. Switching on

Open [revenantal.com](https://revenantal.com). The picture comes up on your last channel, or the TV Guide on your first visit.

If the simple list is showing, choose **Turn on the TV**. On smaller screens the list is the whole site. Reduced-motion visitors start there too.

## 2. Tuning the picture

| Control         | Operation                                                            |
| --------------- | -------------------------------------------------------------------- |
| Channel knob    | Click for the next position. Scroll or drag to turn the dial.        |
| Channel readout | Shows the selected position and programme name when you tune.        |
| Volume knob     | Click its left or right half, scroll, or drag up and down to adjust. |
| Power light     | Switch off the set and open the simple directory.                    |

The unnumbered dial turns through the available channels and a few empty positions. An empty position shows **NO SIGNAL**. That is normal.

Projects open in a new tab, so your programme is still there when you return.

## 3. Front-panel buttons

**STEAM** and **GITHUB** open the profiles. **DISCORD** copies the username. **SERVERS** takes you straight to the server rack.

Server addresses are shown only where enabled. Select a published address in the rack and press Enter to copy it, then connect from your game client.

## 4. Behind the little door

Open the settings door to find the picture and sound switches.

| Switch | Controls                       |
| ------ | ------------------------------ |
| SCAN   | Scanlines across the picture   |
| FLK    | Tube flicker                   |
| FX     | Static between channels        |
| SND    | Sound                          |
| GLOW   | Light spilling from the screen |

Some programmes soften picture effects for readability. An amber lamp shows when the current channel limits an effect. Your OFF setting always wins.

The **Credits** button closes the door and tunes to the credits roll. Pause it to read, follow a source link, or restart from the top. With reduced motion, credits are a still, scrollable list.

## 5. Remote control not included

The keyboard works just as well. Focus the TV before using these controls.

| Key           | Operation                            |
| ------------- | ------------------------------------ |
| ↑ / →         | Next channel                         |
| ↓ / ←         | Previous channel                     |
| + / −         | Adjust volume                        |
| Tab           | Move between controls and links      |
| Enter / Space | Activate a focused button            |
| Esc           | Release game controls back to the TV |
| C             | Toggle captions on a film or clip    |

Text inputs keep their own typing keys. Games take the controls after **PRESS START**; until then, the arrows still turn the dial.

The first Tab stop is **Skip to the simple list**.

## 6. Switching off

Press the power light. The picture closes down and the same projects and servers appear as a plain list. You can carry on browsing there for as long as you like.

Your channel, volume and switches are remembered on this device. Copy the page address to share a dial position.

## 7. Reception notes

| Symptom                        | What to check                                                                    |
| ------------------------------ | -------------------------------------------------------------------------------- |
| No sound                       | Try the volume knob and SND switch. Sound starts after your first interaction.   |
| NO SIGNAL                      | You have reached an empty dial position. Keep turning.                           |
| A status says unknown or stale | The last observation is missing or too old. It does not mean the server is down. |
| No local forecast              | The forecast is optional. The guide carries on without it.                       |
| Less movement than expected    | Reduced-motion preferences and performance settings soften the effects.          |
