# Beta38 Response Fixtures

Derived from owner-supplied Client API responses on 2026-10-18. The restricted account returned one assigned server with server_owner=false and no startup variables; its resources request succeeded with zero selected subuser permissions.

Identity, UUID, internal ID, node, names and SFTP address are replaced. The startup command is a deliberately fake privacy-test sentinel. Allocation 0.0.0.0 and its label demonstrate a bind address rather than a usable connect address. Resource numbers retain the observed shape and units without identifying a server. No actual commands, passwords, API keys or player names are saved.
